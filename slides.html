Beagle Brigade

At US airports the USDA's Beagle Brigade sniffs luggage for what shouldn't cross the border. Scout does the same job for package registries.

Attackers don't break in. They publish.

A stolen maintainer token becomes a new version of a package you already depend on. It runs on every laptop and every CI runner that installs it, before anyone opens a file. This happened thousands of times on npm and PyPI in the past year.

Install-time execution matters most. Code in a postinstall hook runs on every machine that installs the package. But thousands of legitimate packages compile native code that way, so that alone proves nothing. What is almost never innocent is install-time execution combined with credential access, or obfuscation combined with a loader.

Precision

Tuned against live registry traffic

We ran the rules on real npm and PyPI releases and tuned them until legitimate packages score clean while every malware fixture still scores 100. Each pattern below now has its own negative test case.
