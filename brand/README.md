# Scout the beagle

Beagles are scent hounds: the USDA's "Beagle Brigade" sniffs luggage at US airports for prohibited food and plants. Scout sniffs out threats.

| File | Use |
|---|---|
| `beagle-mascot.svg` / `.png` | Default pose |
| `beagle-alert.svg` / `.png` | Alert state, for when Scout "barks" |
| `beagle-avatar.svg` / `.png` | Round badge for the favicon, Slack bot avatar, or slide corner |

The SVGs are the editable sources. The PNGs have transparent backgrounds (1024px for the mascot and alert, 512px for the avatar).
